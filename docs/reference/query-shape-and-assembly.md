# Query shape and assembly — retired

Automatic query-shape budgets, evidence-coverage assembly, and package token fitting are no longer part of Grimoire's CLI or MCP product path.

The active interface preserves heterogeneous evidence instead of predicting a complete answer-shaped package. Each discovery lane has an independent limit, and the consuming agent chooses which handles to expand.

Historical calibration reports remain valid records of the retired package pipeline, not current behavior.

See [Unified discovery contract](agent-query.md).
