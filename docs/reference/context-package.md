# Context package — retired

The context-package interface is no longer part of Grimoire's CLI or MCP product contract.

Grimoire now returns progressive discovery evidence through independent exact, source, document, symbol, and relationship lanes. Consumers follow stable handles with `inspect`, `trace`, or `impact` rather than receiving a token-fitted package assembled before investigation.

Historical version-8 package reports remain in repository history and checked-in evaluation artifacts where needed for comparison. They must not be used as current API documentation.
