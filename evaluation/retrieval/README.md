# Historical retrieval corpora

These frozen corpora describe the retired context-package retrieval pipeline. The source evaluator and `evaluation/run_retrieval_suite.py` runner have been removed with that product path.

The files remain only to interpret checked-in historical reports and earlier calibration decisions. They are not active Grimoire discovery tests and may reference source files or package stages that no longer exist.

Current source, document, symbol, relationship, and end-to-end agent discovery evaluation is documented in [`../../docs/development/testing-and-benchmarks.md`](../../docs/development/testing-and-benchmarks.md).
